Co-founder: Claude Code and Codex skills for solo founders

An open-source pack of Claude Code skills for solo founders that also installs as a Codex co-founder skill: one entry skill and 13 workflows that run inside your existing session.

The same SKILL.md files serve as Claude co-founder skills in Claude Code and as Codex skills for founders in Codex CLI/IDE. It adds no hosted service, mandatory model API, credential scraping, telemetry or automatic agent team. Your host keeps using its normal subscription allowance.

Source code on GitHub · MIT license · version 1.1.1

Install

With Node.js/npm and the third-party skills CLI:

npx skills add jpmishra1010/co-founder-skills --skill co-founder --agent codex claude-code --global

Python 3.10+ is needed for the bundled project-context and validation helpers. Then open your own product in the host and invoke /co-founder in Claude Code or $co-founder in Codex.

Thirteen founder workflows

WorkflowWhat it does
decideResearch and challenge assumptions; compare smaller alternatives.
feature-planDefine users, states, recovery, permissions and acceptance criteria.
impact-mapTrace shared data and modules a change must preserve.
build-fixReproduce, diagnose and implement authorized, bounded changes.
verify-releaseRun relevant checks and distinguish release states.
security-reviewReview trust boundaries, deny paths and sensitive operations.
ui-polishImprove an existing product using its own design language.
customer-careFollow an issue through to a verified customer outcome.
growthChoose a measurable experiment around the real bottleneck.
salesPrepare relevant demos and truthful proposals and follow-ups.
financeTrack cash, runway, pricing and revenue from sourced records.
content-studioProduce project-specific posts, campaigns and motion.
founder-briefSurface a small set of priorities from fresh evidence.

What it is not

A working method for the agent you already use, not a new model or an autonomous legal or business partner. Publishing, sending, deployment, spending and scheduling stay separately authorized by you. Model behavior inside authenticated Claude Code and Codex sessions has not been tested by this project; local tests cover structure and helpers only.

No perfect-design, security, revenue, virality, search-ranking or usage-saving guarantee.
