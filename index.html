Co-founder: Claude Code and Codex skills for solo founders

An open-source pack of Claude Code skills for solo founders that also installs as a Codex co-founder skill: one entry skill and 13 workflows that run inside your existing session. Decide, build, verify, support, sell and track the money with evidence, not guesswork.

npx skills add jpmishra1010/co-founder-skills --skill co-founder
View on GitHub → Then type /co-founder in Claude Code or $co-founder in Codex.
How it works

No new app. Your agent learns how a founder works.

The same SKILL.md files serve as Claude co-founder skills in Claude Code and as Codex skills for founders in Codex CLI/IDE. Your host keeps its normal subscription allowance.

  1. Install once

    One npx skills add command adds the entry skill and all 13 workflows to Claude Code, Codex or both.

  2. Bind your project

    Open your own product, not this repo. Co-founder reads it read-only first and proposes the project and brand binding for you to approve.

  3. Ask like a co-founder

    Describe the problem in plain words. It routes to one workflow, works from evidence and stops before anything consequential.

Thirteen founder workflows

One conversation, from idea to invoice.

Each workflow has its own review principles. Only the one you need is loaded.

Think 3

decide

Research and challenge assumptions; compare smaller alternatives.

Integration first, or fix onboarding?
feature-plan

Define users, states, recovery, permissions and acceptance criteria.

Plan team invites with roles.
impact-map

Trace shared data and modules a change must preserve.

What breaks if invoice numbering changes?

Ship 4

build-fix

Reproduce, diagnose and implement authorized, bounded changes.

Exports are blank for some accounts.
verify-release

Run relevant checks and distinguish release states.

Is this branch ready to ship?
security-review

Review trust boundaries, deny paths and sensitive operations.

Review the new billing webhook.
ui-polish

Improve an existing product using its own design language.

The settings page feels cluttered.

Run 4

customer-care

Follow an issue through to a verified customer outcome.

Close the loop on the export bug.
sales

Prepare relevant demos and truthful proposals and follow-ups.

Prep tomorrow's demo for a clinic.
finance

Track cash, runway, pricing and revenue from sourced records.

How many months of runway do I have?
founder-brief

Surface a small set of priorities from fresh evidence.

What should I do today?

Grow 2

growth

Choose a measurable experiment around the real bottleneck.

Signups are flat this month.
content-studio

Produce project-specific posts, campaigns and motion.

Turn this release into a launch post.
Guardrails

A co-founder that knows what it shouldn't do.

A working method for the agent you already use, not a new model or an autonomous legal or business partner.

Never

  • Runs a hosted service or calls a mandatory model API
  • Collects telemetry or scrapes credentials
  • Launches an agent team behind your back
  • Publishes, sends, deploys, spends or schedules without your approval
  • Moves money or gives tax, legal or investment advice

Always

  • Binds work to the right project and brand first
  • Works from evidence: reproductions, checks and sourced records
  • Says blocked, inconclusive or ready for human review, honestly
  • Keeps private project context inside your own repository
  • Loads one workflow at a time
Honest status

What has and hasn't been tested.

Tested locally

Pack structure, links and the Python helpers, through the repository's validator and unit tests.

Not yet tested

Model behavior inside authenticated Claude Code and Codex sessions.

No guarantees

No perfect-design, security, revenue, virality, search-ranking or usage-saving guarantee.

Give your agent a co-founder's habits.

Needs Node.js/npm for the installer and Python 3.10+ for the bundled helpers.
