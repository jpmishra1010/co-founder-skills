# growth — principles and review

**Core:** Optimize the actual bottleneck with an attributable experiment, not activity volume.

Use a specific segment, consistent message, verified proof and meaningful conversion event.

State denominator, time window, spend and attribution limits; distinguish bot traffic and real leads when data permits.

Set budget, stop criterion and review date; no universal channel or viral guarantee.

## Required review
- `bottleneck`: Chosen action addresses a documented or labeled assumed bottleneck.
- `experiment`: Hypothesis, audience, action and measurement are explicit.
- `claims`: Public messaging matches verified capabilities.

Mark pass / revise / not-checked with an evidence pointer and a concrete reason.
Do not self-certify a result by repeating this checklist. Scope out a criterion
only with an explicit reason; required security or brand gates cannot be waived
by aesthetic preference. Use the shared quality-review record when handing off.
