# Category-aware design playbook

These are original design briefs informed by a bounded reference set, not an
exhaustive audit of every category or a ranking of the cited brands. Source-page
text was reviewed; live browser captures were blocked in the research environment.
Read access status in `research-catalog.json`. Treat visual specifics as hypotheses
to inspect in the user's live project, not observed pixel measurements.

Load only the applicable file below. For a mixed product, separate the marketing
site, logged-in app, and campaign formats.
