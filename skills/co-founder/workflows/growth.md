# Prioritize marketing that can be measured and maintained

## Project binding and quality
Resolve the project using `references/project-identity.md`; bind this task to
its project ID, environment and, for visuals, the approved surface/brand bundle.
Read `references/principles/growth.md`. Apply its evidence-backed review
before handoff. Wrong-project context or an unapproved consequential action
is a blocker, not a missing detail to guess.

## Use and context
Use for positioning, channels, acquisition, activation, landing-page messaging,
SEO, and experiments. Read company brief, verified capability/claims records,
customer evidence, available analytics, and resource constraints. No automatic
ad spend, publishing, scraping personal contacts, or analytics account access.
Read `references/growth-and-sales.md` and current primary platform documentation
when implementation depends on a changing rule.

## Procedure
1. Identify the current bottleneck: awareness, qualified interest, activation,
retention, referral, or sales follow-through. Ask for the smallest missing data;
do not default to "post everywhere". Separate conversion rates from counts.
2. Define a concrete customer segment, job, current workaround, positioning,
credible proof, and next action. Exclude proposed/unreleased capabilities from
public copy. Label anecdotal evidence and unmeasured assumptions.
3. Audit the available journey from message to landing page to sign-up/demo to
successful use. Check message consistency, friction, performance, usability,
trust, and follow-up before prescribing more traffic.
4. Choose a small experiment with a hypothesis, audience, channel, artifact,
baseline, primary measure, cost/time cap, observation window, and stop/continue
criterion. Account for low sample sizes and attribution uncertainty.
5. Prepare a realistic cadence. Repurpose verified releases, useful workflows,
and customer questions. Personal-brand content requires the founder's real
experience, not invented stories. Route assets to content-studio.
6. For search visibility, prioritize crawlability, clear content, canonical URLs,
accurate structured data where applicable, documentation, internal links, and
useful original material. Check current official guidance; never guarantee
rankings, AI citations, traffic, or sales.
7. Review actual results and alternative explanations. Retain an experiment log;
double down, revise, or stop on evidence, not vanity metrics or sunk effort.

## Deliverable
Positioning statement, prioritized bottleneck, one or a few experiments, content
briefs, measurement plan, and explicit assumptions. Use `growth-experiment.md`.
Draft publishing/ad changes for approval; record actual external actions only
when an authorized tool has confirmed them.

## Done
The founder knows the next useful growth action and how its outcome will be
judged. Sometimes resolving a customer issue or following up with a prospect is
more valuable than producing another post; say so with supporting context.
