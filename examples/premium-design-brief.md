# Synthetic design brief: a business operations screen

Audience: busy staff completing operational work, not browsing a luxury campaign.
Goal: find the next action and read relevant status without unnecessary decoration.
Visual thesis: calm, precise, useful. This is a proposed brief, not observed user research.

Retain existing approved brand colors and real components. Use an intentional type
scale, aligned numeric data, consistent gutters, restrained surfaces and semantic
status. Make primary actions clear without saturating every card. On narrow screens,
recompose the density; do not shrink desktop tables until labels are unreadable.

Verify direct load, navigation, refresh, shared header/footer, empty/error/loading,
long names, keyboard focus and the relevant device widths. Screenshot review is
separate from checking persistence, roles and permissions. Report missing tests.

Reference application: inspect the appropriate category sources and approved
screenshots before borrowing a principle. Aesop-like imagery would not justify
hiding the operational data; a complex dashboard would not justify unreadable type.
