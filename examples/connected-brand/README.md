**Northline** and **Fieldnote** are fictional names and original sample artwork.
They are not claims about an existing business, cleared trademarks or approved
branding for the user's products. Do not apply their palette to another project.

The UI is an interactive local fixture, not a production application. Search,
filters, sort, selected repair, a new-record dialog, inventory/activity views and
repeat-completion handling work in memory. Nothing is saved to a server. Fresh
loads reset the demonstration. No authentication or tenant-security implementation
is claimed. All names/records are synthetic.

## What connects the work

An exact logo, restrained forest/neutral palette, typography, plain language and
one service-record concept are shared across the selected brand. The post's warmer
background is an explicit surface override, not an accidental color drift. UI
uses a practical queue/detail composition; advertising uses a tangible ticket;
motion preserves that record through the repair/stock/retry/report sequence.

The second brand uses different artwork, warm-red colors and serif-led typography.
The same binding-proof template renders it separately. Tests check project/profile/
asset mismatch, stale assets and incorrect selection rather than merely trusting a
folder name. None of these examples becomes another project's default.

## Motion narrative

| Approximate interval | Communication job |
|---|---|
| 0–3.4s | Establish the problem: one repair should not become three disconnected tasks. |
| 3.4–8.2s | Complete the repair on one persistent service record. |
| 8.2–12.8s | Transform that record into its stock consequence: 24 becomes 23, once. |
| 12.8–17.9s | Send a repeated request; show that the stock count remains 23. |
| 17.9–21.6s | Reconcile repair, inventory and movement into the report. |
| 21.6–24s | Return to the shared campaign statement. |

These are authored scene choices, not timings extracted from inaccessible films.
The export has 720 frames at 30 fps, silent H.264 1280×720. It is an illustrative
workflow, not footage proving a real product feature. Inspect full playback before
adopting the direction. Sampled stills and state tests do not certify pacing/audio.

## Project records and rights

Only the two intentional fictional `.co-founder/{project,brand,assets}.json` records
are public. They include original vector logos and source hashes. Do not replace
these fixtures with private customer context. System fonts are referenced by name;
font files and external reference artwork are not included.
