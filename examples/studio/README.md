# Legacy v1 diagram-studio smoke fixtures

These are preserved for compatibility and renderer tests, **not** the recommended
look or quality benchmark. Their universal headline/diagram composition was rejected
as insufficiently expressive. Do not apply it to a user's brand by default.

Use the [new connected examples](../connected-brand/README.md) and project-bound
craft workflow. `media.py` still builds old JSON configurations; it does not import
schema-2 project profiles. Existing user files are not migrated automatically.
