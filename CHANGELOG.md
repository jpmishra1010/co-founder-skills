# Changelog

## 1.1.1 — 2026-09-23

- Made the external `npx skills add` route the primary public installation method.
- Retained the conservative Python installer as an offline fallback; clarified that
  Python remains required for executing project/brand/evidence helpers.
- Documented local/GitHub sources, core/shortcut dependencies, manager migration,
  third-party telemetry, and publication acceptance. No custom npm package added.
- Included MIT license text in each installable skill and notices in the core.
- Added isolated-directory distribution tests without changing approved creative
  source, workflows, examples or helper implementations.
- Registry access was unavailable; real npx installation remains unverified.

## 1.1.0 — 2026-09-23

- Added explicit project resolution, optional multi-project registry and separate
  product/personal brand/surface profiles. Exact assets carry project IDs and hashes.
- Added scoped asset inventory, task binding and stale-context checks. General work
  avoids loading creative assets. Existing schema-1 brand records are preserved.
- Added principles and review contracts for all 12 workflows, plus a structural
  quality gate that cannot claim human approval or certify visual/security quality.
- Reworked creative guidance into four disciplines with actual reference inspection,
  concept/storyboard approval, source-preserving production, critique and revision.
- Replaced featured v1 visuals with an original connected UI/post/motion example,
  a distinct second-brand fixture and an optional trusted-HTML local renderer.
- Revised mobile details after inspection and added interaction/isolation checks.
- Expanded helper tests and model-evaluation specifications. Model scenarios remain
  not-run; source-film/full audiovisual and live-host limits remain explicit.
- Added migration, project-setup, workflow-audit, craft and updated rendering docs.

## 1.0.0 — 2026-09-23

Initial skill pack with 12 workflows, private context templates, conservative
installer, bounded local helpers and simple creative smoke fixtures. Its featured
visuals did not meet the requested creative standard and are deprecated in 1.1.
