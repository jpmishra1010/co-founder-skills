## What remains unverified

**Live host use:** No authenticated Codex or Claude Code account was available for
model-driven tests. Skill discovery, permission behavior, instruction adherence,
real usage, and performance must be checked using ACCEPTANCE.md (`ACCEPTANCE.md`, historical reference).
The host adapters follow reviewed official documentation, but documentation
compatibility is not a substitute for an executed host test.

**Browser navigation:** The environment blocks URL navigation, including localhost,
with `ERR_BLOCKED_BY_ADMINISTRATOR`; external access also encountered DNS/network
limits. The successful smoke run therefore used the explicit inline-document mode.
Actual URL navigation and origin-backed reload persistence are marked **not run**,
not silently counted as passes. No browser policy was bypassed.

**Other environments:** GitHub Actions is configured, not executed. macOS, Windows,
other Python/browser versions and optional integrations have not been run here.

**Research viewing:** Official documentation and accessible source-page text were
reviewed, plus two accessible brand/motion stills. External reference films were
not played in full, restricted social feeds were not audited, and no exhaustive
pixel-level review of all website categories is claimed. See RESEARCH.md (`RESEARCH.md`, historical reference).
The category and motion guides distinguish original recommendations from source
observations. Reference artwork, videos and fonts are not bundled.

**Production outcomes:** No actual customer bug, deployment, account integration,
security certification or marketing result is asserted. Tests cannot prove the
model will always comply or that the package is free of defects. The structural
gate checks recorded fields; it does not authenticate approvals or prove coverage.

## Reproduce locally

From the extracted repository:

```sh
python scripts/validate.py
python -m unittest discover -s tests -v
```

Optional browser tests after explicitly installing the documented media dependencies:

```sh
python scripts/browser_smoke.py --out /your/new/output-folder
```

Use `--offline-fixture` only when intentionally limiting the test to inline DOM and
layout behavior. See MEDIA.md (`MEDIA.md`, historical reference) for browser selection, original asset
rendering and environment-specific dependencies. Media dependencies are not needed
for core installation or text/code workflows.

Run the host acceptance checklist on a disposable project before consequential
use. Keep future failures and not-run checks visible in release notes.
